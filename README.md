# Tourism and Travel Booking System

## Project Overview

The Tourism and Travel Booking System is an Agile software project designed to help tourists browse destinations, search tour packages, make bookings, process payments, and manage their travel reservations.

## Project Management

The project is managed using Trello for Agile planning and GitHub for documentation and version control.

## Main Features

- User Registration and Login
- Browse Destinations
- Search Tour Packages
- View Package Details
- Tour Booking
- Online Payment
- Booking Confirmation
- Booking Management
- Admin Package Management
